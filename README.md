# Simple Interest Calculator

A Bash script that calculates simple interest based on user input.

## Formula
Simple Interest = (Principal × Rate × Time) / 100

## Input Fields
- Principal amount
- Rate of interest (annual %)
- Time period (in years)

## Usage
Run the script and enter the required values when prompted.

## Example
Principal: 1000
Rate: 5
Time: 2
Simple Interest = 100
